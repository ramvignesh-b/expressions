# Expressions Digital Magazine Archive

Welcome to the official repository for the web versions of "Expressions," a yearly digital publication. This archive hosts the interactive online editions of the magazine.

## Available Editions

Currently, the following editions are available:

*   [Expressions '24](./2024/magazine.html)
*   [Expressions '23](./2023/index.html)
*   [Expressions '22](./2022/index.html)
*   [Expressions '20](./2020/index.html)

## How to View

There are a couple of ways to explore the magazines:

1.  **Main Landing Page:** Open the `index.html` file in the root of this repository. This will take you to the "Hall Of Tapestries," where you can visually navigate to the different yearly editions.
2.  **Direct Access:** You can also navigate directly to a specific year's magazine by opening the appropriate file:
    *   For 2024: `2024/magazine.html`
    *   For 2023: `2023/index.html`
    *   For 2022: `2022/index.html`
    *   For 2020: `2020/index.html`

## Repository Structure

*   Each year of the publication has its own directory (e.g., `2024/`, `2023/`, `2020/`). These directories contain all the necessary files (HTML, CSS, JavaScript, images, and data) for that specific edition.
*   The `assets/` directory in the root contains shared resources for the main `index.html` landing page.
*   The main `index.html` at the root serves as a central portal to all available editions.

## Technical Details

*   The interactive magazine versions are generated using **Flip PDF Professional** (from flipbuilder.com), which converts PDF documents into a web-friendly flipbook format.
*   The landing pages and overall site structure are built with HTML, CSS, and JavaScript.
*   The main "Hall Of Tapestries" landing page utilizes the [Bootstrap](https://getbootstrap.com/) framework.

## Contributing

The content for "Expressions" is typically created and compiled into a PDF format first, which is then processed by Flip PDF Professional. If you are interested in contributing to future editions, please reach out to the project maintainers to discuss content submissions.

At this stage, direct code contributions to this repository are likely focused on improving the landing pages or fixing display issues. If you encounter a bug or have a suggestion, please open an issue.
